# 粤语练习台 · canto-learn

杨万的手机粤语学习网页。2026-09-15 从旧卡片站重构为“课程原句 → 逐字粤拼 → 单字音频 → 整句/整组音频”的长期课程底座；2026-09-16 纳入第二课代词与问句。

## 当前第一课

1. 音节结构：声母 onset + 韵母 final + 声调 tone。
2. LSHK 粤拼 1–6 与六个相对音高轮廓。
3. 普通话母语者易混对：1↔3、3↔6、4↔6、2↔5、5↔6。
4. 入声韵尾 checked endings：-p / -t / -k。
5. `aa/a`、`ng-`、成音节鼻音、`-m/-n/-ng`、`oe/eo`、`z/c/s`、`j/gw/kw` 的第一遍辨认。
6. 10 题随机听辨基线：覆盖 `si`、`fan` 与数字三组样音；成绩只存本机，不设任意及格线。

## 当前第二课

1. 人称代词：我／你／佢 + 哋。
2. 指示／疑问组合：呢／嗰／邊 × 個／度／啲的九个组合（邊属于疑问语）。
3. 疑问表达：咩、乜嘢、邊個、邊度、邊啲、點樣、點解，以及是非问句格式係咪。
4. 易混点：係／喺、嘢／嘅、咩／咪、所有格嘅 ge3／本课问原因句末嘅 ge2。
5. 22 句课堂与补充例句，每句都有自然整句音频和逐字点读。
6. 否定词速览：唔、冇、未、咪；并区分定係、仲係、都係与仲未。

首页是短课程树，不直接展开长课文；第一、二课进入后也只显示课内目录，一次打开一个章节，第二课句子与否定词再按小组折叠。移动端多字词与句子都同时提供整词／整句播放和逐字按钮，并用 `<ruby><rt>` 显示具体语境中的粤拼。播放器一次只播放一段音频，支持 0.75× / 1× / 1.25× 和 1× / 3×。网页可安装为 PWA，访问过的音频按需离线缓存。

## 数据与音频边界

- `course.js` 是第一课数据源，`lesson-02.js` 是第二课数据源；每个页面只加载本课数据，不复制同一课内容。
- 后续课堂句子使用 `sentenceAudio + tokens[{char, contextualJyutping, charAudio}]`，逐字记录语境读音；标点不设音频。
- 单字练习音与自然整句录音是两种资产，禁止把单字文件机械拼成“整句”。
- 现有音频是 Microsoft `zh-HK-HiuMaanNeural` 生成的练习样音，已检查文件可解码，但不等于老师或母语者人工纠音。
- `樣_joeng2`、`咪_mai6`、`嘅_ge2` 不能用孤立字 TTS 得到正确语境调；它们从同一音色的「點樣？／係咪？／講嘅？」中按波形边界切出，只供逐字辨音，仍待真人复核。
- 标音参考 [LSHK Jyutping](https://jyutping.org/jyutping/)、[粵典 words.hk](https://words.hk/) 与 [中大粤语审音配词字库](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-can/)；多音字和变调仍须按课堂语境逐项复核。
