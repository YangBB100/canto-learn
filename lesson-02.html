01 / 人称代词

一个「哋」，把单数变复数

哋 dei6 是表示复数的后缀。课堂写的「你地／佢地」统一改作粤语字 你哋／佢哋。

先改正三组课堂速记

食咪 → 食咩 me1 你地 / 佢地 → 你哋 / 佢哋 dei6 佢 heoi3 → 佢 keoi5；去 heoi3

02 / 指示与疑问组合

呢、嗰、邊，和三个尾巴组合

呢／嗰是指示语，邊是疑问语；再接「个／地方／些」。九个组合不是九条死记词，而是一张可以自己生成的表。

← 返回本课目录

03 / 疑问表达

问什么、谁、哪里、怎样、为什么

咩 me1 是日常常用的「什么」；乜嘢 mat1 je5 是完整形式。係咪不是疑问代词，而是构成是非问句的格式。

← 返回本课目录

04 / 易混点

字看着近，功能和声调不同

这里先按功能成对记。尤其注意：係 hai6 是低平调，不是下降调；本课询问原因的句末「嘅」读 ge2，所有格读 ge3。

本课完成标准

能在身份、地点和归属之间换问法，就算学会。

  • 能说出我哋／你哋／佢哋，并听清 佢 keoi5 与 去 heoi3。
  • 能用呢／嗰／邊加個／度／啲，自己生成九个组合。
  • 能分清 係 hai6（是）和 喺 hai2（在），以及咩／咪、嘢／嘅。
  • 能解释选择的 定係、仍然的 仲係、权衡后的 都係…啦。
